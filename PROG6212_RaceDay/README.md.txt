# RaceDay - Event Management Platform

RaceDay is a full-stack event management platform designed specifically for the South African road running, walking, and cycling community. The system connects race organisers and participants to streamline event registrations, live logistics, and verified result tracking.

## System Roles

* **Organiser:** Has full administrative rights to create and delete events, configure race distance categories, supply route and logistics data, view participant enrolments, and capture verified race results.
* **Participant:** Can create an account, browse scheduled race events, enrol in specific categories, track personal race entries, and view public race results.
